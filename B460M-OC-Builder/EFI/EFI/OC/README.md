# B460M-PLUS EFI staging tree

This directory is a staging layout, not yet a bootable EFI. The generated config.plist is a DEBUG candidate only and contains the temporary test SMBIOS serial/MLB/ROM/UUID values explicitly approved for initial bring-up; the user will replace them locally with a fresh matching GenSMBIOS set after initial testing.

- `ACPI/`: three official Dortania AML files, copied byte-for-byte and verified against upstream, plus one board-specific RHUB DSL source awaiting compilation.
- `Kexts/`: official release manifest and intended load order; CI downloads and extracts the pinned release bundles into each generated artifact rather than checking binaries into the source tree.
- `Drivers/`: required UEFI driver manifest; CI stages OpenRuntime from the matching OpenCore package and the pinned HfsPlus binary into each generated artifact.
- `config.plist`: generated by the staging workflow from the matching OpenCore 1.0.8 Sample.plist and checked with matching `ocvalidate`. The repository source tree does not contain a checked-in generated config.plist; it is created inside the CI artifact. The artifact remains staging-only and is not approved to boot until the separate USB-media and hardware-validation gates are completed.

Hardware plan and outstanding validation: see `B460M-OC-Builder/Hardware-Kext-Plan-2026-11-25.md` and `B460M-OC-Builder/ACPI-Analysis-Report-2026-11-25.md`.
