# B460M-PLUS EFI staging tree

This directory is a staging layout, not yet a bootable EFI. The generated config.plist is a DEBUG candidate only; SMBIOS serial/MLB/ROM/UUID are intentionally blank until fresh values are generated and applied locally.

- `ACPI/`: three official Dortania AML files, copied byte-for-byte and verified against upstream, plus one board-specific RHUB DSL source awaiting compilation.
- `Kexts/`: official release manifest and intended load order; actual bundles still need to be downloaded/extracted.
- `Drivers/`: required UEFI driver manifest.
- `config.plist`: generated by the staging workflow and checked with matching OpenCore 1.0.8 ocvalidate. It intentionally has blank SMBIOS serial/MLB/ROM/UUID fields. Do not boot until fresh values are generated locally, applied, revalidated, and USB mapping plus hardware testing are complete.

Hardware plan and outstanding validation: see `B460M-OC-Builder/Hardware-Kext-Plan-2026-11-25.md` and `B460M-OC-Builder/ACPI-Analysis-Report-2026-11-25.md`.
